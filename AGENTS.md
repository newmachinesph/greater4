# Greater4 house rules

- **Monochrome only.** There are no colour tokens. If you reach for one, the
  answer is scale, weight, tracking, or a wash — see `app/globals.css`.
- **Numbers are sourced.** Every figure in `lib/catalog.ts` and in page copy
  traces to the USAP rulebook, DUPR, PPF, or SM Active Hub. Verify before
  editing; the brand argument depends on them being right.
- **Copy test.** Swap a competitor's logo into any headline. If it still works,
  rewrite it. See `DECISIONS.md` for the positioning this protects.
- Read `PROJECT.md` first — it lists what is still a placeholder.
