# Greater4

Marketing site for a Philippine premium pickleball brand built around doubles.

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # 11 static routes
npm run lint
```

Next.js 16 App Router · React 19 · Tailwind v4 · fully static, no runtime deps.

See `PROJECT.md` for current state and what is still placeholder,
`DECISIONS.md` for why the brand and design are the way they are,
`AGENTS.md` for house rules before editing.
